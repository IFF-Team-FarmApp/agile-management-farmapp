# agile-management-farmapp
Prototype of a pharmaceutical app developed using Scrum and Kanban methodologies, with task management in Trello and UI/UX design in Figma.  This project is being developed for the Software Development Processes class in the Information Systems program at Instituto Federal Fluminense (IFF).
